# Контур цен — демо мониторинга конкурентов

Локальный портфельный проект на Node.js и встроенной SQLite. На главной странице видны цены по двум демонстрационным магазинам, история, сравнение с целевой ценой, ошибки проверки и экспорт CSV. Можно добавить реальную публичную HTTPS-карточку товара.

## Запуск

Нужен Node.js 22.9 или новее. Дополнительные пакеты не требуются.

```powershell
npm start
```

Откройте <http://127.0.0.1:4175/>. База создаётся в `data/monitor.sqlite` при первом запуске. Для другого порта задайте переменную `PORT`.

Нажмите **Проверить цены**: 8 демонстрационных карточек будут прочитаны из локальных HTML-источников. Чтобы проверить реальный товар, нажмите **Добавить товар** и укажите HTTPS-ссылку. Цена извлекается только из стандартных `product:price:amount`, `price` или JSON-LD `offers.price` / `lowPrice`. Если сайт требует JavaScript, блокирует запросы или не содержит такой разметки, интерфейс покажет ошибку источника; он не подставляет цену из произвольного текста.

Демоданные и семидневная история вымышлены и предназначены только для показа интерфейса. Для коммерческой эксплуатации понадобятся адаптеры под выбранные магазины, соблюдение их правил доступа, расписание проверок, авторизация и хранение настроек источников.
